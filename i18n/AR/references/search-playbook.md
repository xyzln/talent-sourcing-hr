# دليل استراتيجية البحث

> يُستخدم مع الخطوتين 2 و3 من مهارة `recruit-web-sourcing`. الهدف: تغطية معلومات عرض المواهب بشكل منهجي خلال عدد محدود من أدوار البحث.

## 1. مصفوفة طبقات القنوات

| الطبقة | نوع القناة | قنوات نموذجية | الاستخدام الأساسي | جودة المصدر |
|--------|-----------|---------------|-------------------|-------------|
| L1 | مواقع التوظيف | BOSS Zhipin وZhaopin وLiepin وLagou و51job؛ وعالميًا: LinkedIn وIndeed وGlassdoor | الوظائف المفتوحة ونطاقات الرواتب والشروط وكثافة المواهب | عالية (وصف وظيفة أصلي) |
| L2 | المجتمعات الاجتماعية والمهنية | Maimai وZhihu وGitHub وStack Overflow وV2EX وJuejin وBehance/Dribbble (للتصميم) | فرص المرشحين وأعمالهم الحقيقية وتأثيرهم التقني | متوسطة-عالية (منشورات أصحابها) |
| L3 | تحرّكات المنافسين والقطاع | صفحات التوظيف لدى المنافسين وأخبار التمويل/المنتجات ووسائط القطاع | اتجاه توسع المنافسين وإشارات تدفق المواهب | متوسطة (تحتاج تحققًا متقاطعًا) |
| L4 | تقارير وبيانات القطاع | دراسات الرواتب وتقارير سوق المواهب والأوراق البيضاء للمنصات | معايير الرواتب واتجاهات العرض والطلب | متوسطة (تحقق من تاريخ النشر) |

**ترتيب التنفيذ**: L1 أولًا لكثافة العرض ونطاقات الرواتب، ثم L2/L3 لاستخراج فرص محددة، وأخيرًا L4 لمعايرة استنتاجات السوق.

## 2. بناء مصفوفة الكلمات المفتاحية

دمج أربع عائلات من الكلمات بشكل متقاطع، باستخدام 2-4 توليفات لكل دور بحث:

| العائلة | الوصف | المثال (مهندس خلفية أول) |
|---------|-------|--------------------------|
| كلمات الدور | المرادفات وصيغ المسمى | مهندس خلفية، مطوّر خادم، مطوّر Java، Backend Engineer |
| كلمات المهارة | المهارات التقنية والأدوات | الأنظمة الموزعة، الخدمات المصغّرة، التزامن العالي، Kubernetes، Go، Spring Cloud |
| كلمات السيناريو | سيناريوهات العمل والقطاع | منصة تجارة إلكترونية، أنظمة الدفع، SaaS، التكنولوجيا المالية، أنظمة الإعلانات |
| كلمات القناة | المواقع والاستهداف الداخلي | site:zhipin.com، site:linkedin.com، site:github.com |

**أمثلة على التوليفات**:
- «مهندس خلفية أول خدمات مصغّرة تزامن عالي توظيف» ← عرض L1
- «site:github.com تزامن عالي Java مفتوح المصدر» ← فرص تقنية من L2
- «مهندس معماري أنظمة دفع توظيف راتب» ← نطاق الرواتب

## 3. بطاقة عمليات البحث

| العملية | الغرض | المثال |
|---------|-------|--------|
| `site:` | تقييد بموقع | `site:liepin.com مهندس خوارزميات` |
| `intitle:` | يجب ظهورها في العنوان | `intitle:توظيف محلل بيانات` |
| `filetype:` | تقييد نوع الملف | `filetype:pdf تقرير رواتب 2025` |
| `""` | مطابقة تامة | `"مدير نمو المستخدمين"` |
| `-` | استبعاد الضوضاء | `توظيف -تدريب -أمن` |
| مرشّح الوقت | ضبط الحداثة | يُفضّل آخر 3-12 شهرًا للأخبار والوظائف |

## 4. تقييم كثافة العرض (كيف نحكم في الخطوة 3 على «هل المواهب متاحة؟»)

تتبّع أربع مقاييس لكل دور وسجّلها في تقرير الاستقطاب:

1. **حجم الوظائف المفتوحة**: مرتبة الحجم على قنوات L1 (مثل «~500+ على BOSS Zhipin»)
2. **نطاق الرواتب**: النطاق السائد والنسب المئوية (P25/P50/P75)، بتاريخ الحصول
3. **أماكن تمركز المواهب**: الشركات/المدن/المجتمعات التي يتجمّع فيها هذا الجمهور (قائمة المنافسين)
4. **إشارات الندرة**: إعلانات طويلة الأمد، ارتفاع الرواتب، تخفيف الشروط (عجز في العرض) أو العكس

**مستويات الاستنتاج**:
- العرض وفير (حجم وظائف كبير ورواتب مستقرة) ← ارفع المعايير باعتدال؛ وركّز الفرز على مطابقة المهارات
- العرض ضيّق (وظائف قليلة ورواتب مرتفعة وشروط مخففة) ← ابدأ مبكرًا ووسّع الفئات البديلة وارفع ميزانية التعويضات
- الندرة الهيكلية (مجموع كبير لكن القليل يستوفي الشروط الصارمة) ← شدّد أولوية الشروط الحاجبة واستهدف «أقرب الجماعات»

## 5. مسارات الاستقطاب الشائعة حسب الدور (مرجع سريع)

| نوع الدور | القنوات ذات الأولوية | تكتيكات استخراج الفرص |
|-----------|----------------------|-----------------------|
| الهندسة (واجهة/خلفية/خوارزميات) | L1 + GitHub/Juejin | البحث عن مساهمي المصادر المفتوحة ومؤلفي المدونات التقنية |
| المنتج | L1 + Maimai/Zhihu | البحث عن كاتبي تحليلات المنتجات وأخبار منتجات المنافسين |
| التصميم | L1 + Behance/Dribbble | تصفّح الأعمال مباشرة؛ وبحث عكسي عن المؤلفين حسب نوع المشروع |
| العمليات/التسويق | L1 + حسابات WeChat/Zhihu | البحث بتوقيعات الحملات الشهيرة التي أداروها |
| المبيعات/تطوير الأعمال | L1 + Maimai | بحث عكسي حسب شريحة العملاء: «من تعامل مع عملاء مشابهين» |
| الوظائف المؤسسية (موارد بشرية/مالية/قانونية) | L1 + مجتمعات متخصصة | بحث عكسي بالشهادات المهنية (CPA، امتحان المحاماة، إلخ) |

## 6. انضباط البحث

- كل دور يتحقق من فرضية واحدة فقط؛ لا استعلامات «كل شيء في واحد»
- تحقق متقاطع لكل استنتاج بمصدرين مستقلين على الأقل؛ وفي الرواتب الأولية لوصف الوظائف الأصلي على التقارير
- تأريخ جميع بيانات السوق بـ«تاريخ الحصول: YYYY-MM-DD»
- دوران فارغان متتاليان ← غيّر عائلة الكلمات أو القناة؛ ولا تكرر الاستعلام نفسه أكثر من مرتين
