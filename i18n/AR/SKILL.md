# سير العمل للبحث الشامل عن المرشحين ومطابقة المهارات

## الغرض

تحويل متطلبات العمل لدور أو توظيف إلى خطة استقطاب قابلة للتنفيذ: هيكلة المتطلبات، وتصميم البحث الشامل وتنفيذه، وبناء نموذج مهارات ومطابقته بدقة، ثم إخراج تقرير استقطاب مع الخطوات التالية.

## متى يُستخدم

- عندما يقدّم المستخدم وصف وظيفة (JD) أو متطلبات عمل ويطلب إيجاد أشخاص أو البحث عن المواهب أو مسح سوق المواهب أو مقارنة توظيف المنافسين
- عندما يطلب المستخدم فرز فرص المرشحين أو مطابقتها أو ترتيبها حسب أبعاد المهارات
- عندما يطلب تقرير استقطاب أو خريطة مواهب أو ملخصًا عن سوق التوظيف

## سير العمل من خمس خطوات

### الخطوة 1: توضيح المتطلبات وهيكلتها

تحويل متطلبات العمل إلى ملف مواهب منظم؛ والسؤال عند نقص المعلومات، وعدم الافتراض أبدًا. إخراج أربع جداول:

- **الشروط الصارمة**: المستوى / سنوات الخبرة / التعليم / خلفية القطاع / الموقع / نطاق الراتب / تاريخ المباشرة
- **أبعاد المهارات**: المهارات التقنية، ومهارات العمل الناعمة، وعوامل التوافق الثقافي
- **الأوزان**: شروط أساسية (نقض قاطع) / مرغوبة / مرجعية
- **أهداف البحث**: الشركات المستهدفة، والفئات المستهدفة، والفئات البديلة

### الخطوة 2: تصميم استراتيجية البحث

بناء مصفوفة كلمات مفتاحية (كلمة الدور x كلمة المهارة x كلمة السيناريو x كلمة القناة) وقائمة القنوات المستهدفة من ملف المواهب. الطريقة والأمثلة في `references/search-playbook.md`:

- طبقات القنوات: مواقع التوظيف / المجتمعات الاجتماعية والمهنية / تحرّكات المنافسين / تقارير القطاع
- هدف واضح لكل دور: التحقق من كثافة العرض / استخراج فرص محددة / التحقق من مستويات الرواتب ومقاييس السوق
- صيغ الكلمات المفتاحية: المرادفات والاختصارات ومزج EN-ZH (مثل «backend» و«services» و«Backend»)

### الخطوة 3: تنفيذ البحث الشامل

التنفيذ دورًا بدور مع الالتزام بالانضباط التالي:

- تسجيل كل دور: الاستعلام، القناة، عدد النتائج، جودة المصدر، تاريخ الحصول
- التحقق المتقاطع: مصدران مستقلان على الأقل لكل استنتاج؛ والأولوية للمصادر الرسمية والأولية
- تأريخ جميع بيانات السوق والتوظيف بتاريخ الحصول
- عندما لا يُثمر دور، العودة إلى الخطوة 2 لتوسيع الكلمات أو تغيير القناة؛ وعدم تكرار الاستعلام نفسه أكثر من مرتين

### الخطوة 4: بناء نموذج المهارات والمطابقة الدقيقة

1. تفكيك متطلبات الدور إلى 5-8 أبعاد قابلة للتقييم وبناء سلم مراسي سلوكية 0-5 (ما يُقيَّم وكيف يبدو كل مستوى)
2. تقييم كل فرصة مرشح حسب كل بُعد بناءً على الأدلة الواردة في السير الذاتية أو الملفات أو أوصاف المشاريع فقط؛ لا دليل لا تقييم
3. تشغيل `scripts/match_score.py` لحساب المطابقة المرجّحة (المدخل: JSON للتقييمات؛ المخرج: الدرجة الكلية ونقاط القوة والفجوات وأعلام النقض)
4. النموذج التقييمي وأمثلة المراسي وحدود التصنيف في `references/capability-matching-model.md`

### الخطوة 5: إخراج تقرير الاستقطاب

اتباع `references/report-template.md`: تقرير «الاستنتاجات أولًا» يشمل نظرة عامة على عرض المواهب، وجدول أفضل الفرص (درجة المطابقة مع الأدلة)، ونصائح التواصل، والمخاطر مع الخطط البديلة. والختام بثلاثة إجراءات فورية قابل للتنفيذ من صاحب العمل.

## القواعد الحاكمة

- التقييم يعتمد فقط على المهارات المرتبطة بالوظيفة والأدلة؛ ومطلقًا لا على العمر أو الجنس أو المنطقة أو الحالة الاجتماعية أو التسجيل الأسري أو أي بعد تمييزي آخر
- عدم اختلاق مصادر أو مرشحين؛ وعندما لا يُثمر البحث قول ذلك بصراحة واقتراح كيفية توسيعه
- القنوات العامة فقط؛ وحماية خصوصية المرشحين
- إرفاق المصدر وتاريخ الحصول بكل استنتاج
