## 💡 لماذا هذا المشروع

الوكيل العام يجيب على كل شيء قليلاً، أما استقطاب المواهب فيتطلب دقة: المتطلبات يجب تفكيكها، والقنوات يجب تغطيتها، والمهارات يجب تقييمها، والاستنتاجات يجب أن تكون قابلة للتتبع. هذا «الوكيل المؤقت» يأتي مع المنهجية كاملة جاهزة — أنت تقدّم متطلبات العمل، وهو يقدّم تقرير الاستقطاب.

| المشكلة | الوكيل العام | مسؤول استقطاب المواهب |
|:---|:---|:---|
| لا تعرف كيفية إعداد وكيل مؤقت | كتابة prompts بالحدس والحظ | منهجية جاهزة: خمس خطوات + ثلاثة مراجع |
| متطلبات غامضة | يبحث أولًا ولا يسأل أبدًا | يبني ملف مواهب أولًا، ويسأل عند نقص المعلومات |
| لا انضباط في البحث | كلمتان مفتاحيتان وأصابع متقاطعة | مصفوفة كلمات × طبقات قنوات، بحث متعدد الأدوار بتحقق متقاطع |
| المطابقة بالإحساس | «يبدو مناسبًا» | مراسي سلوكية 0-5 + تقييم مرجّح + نقض قاطع |
| استنتاجات غير قابلة للتتبع | مقنع صوتيًا بلا مصادر | كل ادعاء مدعوم بأدلة، وبيانات السوق مؤرّخة |

## ✨ القدرات الأساسية

| # | القدرة | الوصف |
|:--|:---|:---|
| 1 | **هيكلة المتطلبات** | يحوّل الطلبات العامية («نريد مطوّر خلفية يتحمل الضغط») إلى ملف مواهب منظم: شروط صارمة، أبعاد مهارية، أوزان، وشروط حاجبة |
| 2 | **البحث الشامل** | مصفوفة كلمات مفتاحية + طبقات قنوات (مواقع التوظيف / المجتمعات المهنية / تحرّكات المنافسين / تقارير القطاع)، بحث متعدد الأدوار، وتحقق متقاطع لكثافة العرض ومستويات الرواتب |
| 3 | **نمذجة المهارات والمطابقة الدقيقة** | 5-8 أبعاد قابلة للتقييم، سلم مراسي سلوكية 0-5، وحساب مرجّح عبر `match_score.py` ← درجة المطابقة ونقاط القوة والفجوات |
| 4 | **تقرير الاستقطاب** | الاستنتاجات أولًا: نظرة عامة على العرض، جدول أفضل الفرص، نصائح التواصل، خطط بديلة، وقائمة إجراءات 72 ساعة |

## 🔄 سير العمل من خمس خطوات

<img src="assets/workflow_AR.svg" width="100%" alt="سير العمل من خمس خطوات"/>

| الخطوة | المُدخل | المُخرج |
|:--|:---|:---|
| 1. الهيكلة | متطلبات العمل / JD | ملف مواهب (شروط صارمة + أبعاد + أوزان) |
| 2. الاستراتيجية | ملف المواهب | مصفوفة كلمات + قائمة القنوات + أدوار البحث |
| 3. البحث | استراتيجية البحث | سجل النتائج (مصدر + تاريخ + تقييم الجودة) |
| 4. المطابقة | فرص المرشحين + نموذج المهارات | درجة المطابقة + نقاط القوة + الفجوات |
| 5. التقرير | كل النتائج | تقرير «الاستنتاجات أولًا» + خطة عمل 72 ساعة |

## 📊 تقييم المطابقة

التقييم يعتمد فقط على أدلة من قنوات عامة — لا دليل لا تقييم. المتوسط المرجّح × 20 = درجة المطابقة (0-100):

| الدرجة | التصنيف | الإجراء الموصى به |
|:--|:---|:---|
| ≥ 85 | **A · تواصل فوري** | التواصل فورًا برسالة موجّهة |
| 70 – 84 | **B · قابل للتطوير** | التواصل مع تقدير كلفة سدّ الفجوات |
| 50 – 69 | **C · بحذر** | خيار بديل عند ضعف العرض |
| < 50 | **D · غير مطابق** | استبعاده من قائمة الاستقطاب |
| أي شرط أساسي ≤ 2 | **نقض قاطع** | يُصنّف D افتراضيًا ما لم يُعفَ صراحة من صاحب العمل |

## 🚀 البداية السريعة

### الخيار الأول: التثبيت كحزمة خبير (موصى به)

ثبّت هذا المستودع كحزمة خبير لـ WorkBuddy:

```bash
# استنساخ المستودع
git clone https://github.com/xyzln/talent-sourcing-hr.git

# النسخ إلى مجلد الخبراء
cp -r talent-sourcing-hr ~/.workbuddy/plugins/marketplaces/my-experts/plugins/

# التسجيل (السكربت في مجلد scripts/ لمهارة expert-manager)
python3 register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/talent-sourcing-hr
```

ثم اختر **مسؤول استقطاب المواهب** من مركز الخبراء في WorkBuddy واذكر متطلبات عملك — هذا كل شيء.

### الخيار الثاني: استخدام المهارة منفردة

يمكن نسخ مجلد `skills/recruit-web-sourcing/` إلى `~/.workbuddy/skills/` للاستخدام المنفرد، أو تثبيت إصدار اللغة من SkillHub بالبحث عن `recruit-web-sourcing`.

## ⚠️ التزامات الامتثال

- الفرز والمطابقة يعتمدان **فقط على المهارات المرتبطة بالوظيفة وأدلة من قنوات عامة** — بلا أي أبعاد تمييزية تتعلق بالعمر أو الجنس أو المنطقة أو الحالة الاجتماعية أو التسجيل الأسري
- **لا مصادر أو مرشحين مُختلقين** — إذا لم يُفضِ البحث إلى نتائج نقول ذلك بصراحة ونقترح كيفية توسيعه
- المعلومات العامة فقط؛ خصوصية المرشحين محمية
- كل استنتاج يحمل مصدره وتاريخ الحصول عليه
