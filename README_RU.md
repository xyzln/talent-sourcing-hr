## 💡 Зачем это нужно

Универсальный агент отвечает на всё понемногу, а подбор талантов требует точности: требования нужно декомпозировать, каналы — покрыть, компетенции — оценить, выводы — сделать проверяемыми. Этот агент-подрядчик поставляется с готовой методологией — вы приносите требования бизнеса, он приносит отчёт по подбору.

| Боль | Универсальный агент | Офицер по подбору |
|:---|:---|:---|
| Не знаете, как настроить временного агента | Промпт на глаз, упование на удачу | Готовая методология: 5 шагов + 3 справочника |
| Размытые требования | Сначала поиск, вопросы — никогда | Сначала профиль таланта; при нехватке данных — уточняющие вопросы |
| Нет дисциплины поиска | Пара ключевых слов и пальцы скрещены | Матрица ключевых слов × слои каналов, многораундовый поиск с перекрёстной проверкой |
| Соответствие на глаз | «Выглядит подходяще» | Поведенческие анкеры 0-5 + взвешенная оценка + жёсткое вето |
| Непроверяемые выводы | Звучит убедительно, источников нет | Каждый тезис подкреплён доказательством; рыночные данные с датой |

## ✨ Ключевые возможности

| # | Возможность | Описание |
|:--|:---|:---|
| 1 | **Структурирование требований** | Превращает разговорные формулировки («нужен бэкендер, который выдержит нагрузку») в структурированный профиль таланта: жёсткие условия, компетенции, веса, блокирующие критерии |
| 2 | **Поиск по всему интернету** | Матрица ключевых слов + слои каналов (job-сайты / профессиональные сообщества / действия конкурентов / отраслевые отчёты), многораундовый поиск, перекрёстная проверка плотности предложения и зарплатных бенчмарков |
| 3 | **Модель компетенций и точное соответствие** | 5-8 оцениваемых измерений, шкала поведенческих анкеров 0-5, взвешенный расчёт `match_score.py` → grade соответствия, сильные стороны, пробелы |
| 4 | **Отчёт по подбору** | Сначала выводы: обзор предложения, таблица топ-лидов, рекомендации по контакту, запасные планы, список действий на 72 часа |

## 🔄 Рабочий процесс из пяти шагов

<img src="assets/workflow_RU.svg" width="100%" alt="Рабочий процесс из пяти шагов"/>

| Шаг | Вход | Выход |
|:--|:---|:---|
| 1. Структура | Требования бизнеса / JD | Профиль таланта (жёсткие условия + компетенции + веса) |
| 2. Стратегия | Профиль таланта | Матрица ключевых слов + список каналов + раунды поиска |

| 5. Отчёт | Все результаты | Отчёт «сначала выводы» + план действий на 72 часа |

## 📊 Оценка соответствия

Оценка строится только на доказательствах из открытых каналов — нет доказательств, нет оценки. Взвешенное среднее × 20 = оценка соответствия (0-100):

| Оценка | Grade | Рекомендуемое действие |
|:--|:---|:---|
| ≥ 85 | **A · Приоритетный контакт** | Связаться немедленно с точечным сообщением |
| 70 – 84 | **B · Развиваемый** | Контакт + оценка стоимости закрытия пробелов |
| 50 – 69 | **C · Осторожно** | Запасной вариант при дефиците предложения |
| < 50 | **D · Не подходит** | Не включать в список подбора |
| Любой обязательный критерий ≤ 2 | **Жёсткое вето** | По умолчанию D, если бизнес явно не сделал исключение |

## 🚀 Быстрый старт

### Вариант 1: Установка как эксперт-пакет (рекомендуется)

Установите этот репозиторий как экспертный пакет WorkBuddy:

```bash
# Клонировать репозиторий
git clone https://github.com/xyzln/talent-sourcing-hr.git

# Скопировать в каталог экспертов
cp -r talent-sourcing-hr ~/.workbuddy/plugins/marketplaces/my-experts/plugins/

# Зарегистрировать (скрипт в каталоге scripts/ навыка expert-manager)
python3 register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/talent-sourcing-hr
```

Затем выберите **Офицера по подбору талантов** в центре экспертов WorkBuddy и изложите требования бизнеса — всё.

### Вариант 2: Использование навыка отдельно

Каталог `skills/recruit-web-sourcing/` можно скопировать в `~/.workbuddy/skills/` для автономного использования или установить языковую версию с SkillHub, найдя `recruit-web-sourcing`.

## ⚠️ Обязательства по соответствию

- Отбор и сопоставление опираются **только на релевантные должности компетенции и доказательства из открытых каналов** — без возрастных, гендерных, региональных, семейных и иных дискриминационных измерений
- **Никаких выдуманных источников и кандидатов** — если поиск не дал результатов, мы честно об этом скажем и предложим, как его расширить
- Только открытая информация; приватность кандидатов защищается
- Каждый вывод сопровождается источником и датой получения
